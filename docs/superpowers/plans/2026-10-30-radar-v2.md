# Nedbørsradar v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Et offentligt nedbørskort til tv2nord.dk med DMI-radar for de seneste 2 timer og en pysteps-prognose 60 min frem, korrekt placeret på kortet.

**Architecture:** En Python-worker (`radar/`) kører som systemd-timer hvert 2. minut. Den henter nye fullRange-composites fra DMI, laver S-PROG-nowcast, reprojicerer til EPSG:3857 og publicerer palette-PNG'er + `manifest.json` atomisk i `/var/lib/radar/public/`. Nginx serverer data og en vanilla-JS MapLibre-widget (`web/`) statisk og offentligt. Widgetten kan indlejres i Statamic.

**Tech Stack:** Python 3.12, pysteps, rasterio, h5py, pyproj, Pillow, requests, pytest. MapLibre GL JS 4.7.1 (CDN), OpenFreeMap. systemd og Nginx på Ubuntu 24.04.

**Spec:** `docs/superpowers/specs/2026-10-30-radar-v2-design.md`. Referencekode: `spike/run_spike.py` (Warper, grid_transform, zr/to_dbz, pysteps-kald) og `spike/check_georef.py`.

## Global Constraints

- DMI API-base: `https://opendataapi.dmi.dk/v1/radardata`. Brug altid `datetime=<start>/..` og `scanType=fullRange`. Send aldrig API-nøgle.
- Filnavn: `dk.com.{YYYYMMDDHHMM}.500_max.h5`, download-URL `{base}/download/{id}`.
- Rå værdier: `dBZ = raw * gain + offset` (gain 0.5, offset −32 fra `what`). `raw == 255` → NaN (uden for dækning), `raw == 0` → −32 (ingen ekko).
- Grid-transform: hjørner i `where` er pixelcentre → `Affine(xscale, 0, x_UL - xscale/2, 0, -yscale, y_UL + yscale/2)` i `projdef`.
- Z-R: a=200, b=1.6. Regn under 7 dBZ → 0 mm/t. Prognosetærskel 0.1 mm/t.
- Udsnit: `BBOX = (7.6, 54.4, 15.4, 57.9)` (lon_min, lat_min, lon_max, lat_max).
- Takt: `STEP_MIN = 10`, `HISTORY_FRAMES = 12` (2 t obs), `LEADS = 6` (60 min), `MOTION_FRAMES = 3`.
- Farveskala (dBZ-grænser → farve), gennemsigtig under 10 dBZ:
  `[10,15,20,25,30,35,40,45,50,55,∞)` → `#a6e3ff #5ab4f0 #2a7fd4 #1f4fa8 #2fae3c #f2e030 #f5a623 #e8452c #b81f5b #7a1fa2`. Uden for dækning: grå `(90,90,90,70)`.
- Attribution, ordret: `Radardata: DMI (CC BY 4.0)`.
- Tider i UI: `Europe/Copenhagen`, dansk format.
- Server: kode i `/var/www/services/radar/`, data i `/var/lib/radar/` (`StateDirectory=radar`, ejer www-data). Ingen ny port. Nginx-blokken installeres FØR koden lægges på serveren.
- Tests kører i Docker (`Dockerfile.test`), aldrig mod det rigtige DMI-API.

## Review Focus

1. **DMI er nede, langsom eller mangler den nyeste fil** → sidste gode manifest bliver liggende uændret, og workeren afslutter med exit 0 og logger en advarsel. Test: `test_cycle_keeps_manifest_when_dmi_fails` (Task 6).
2. **Tørvejr (ingen ekkoer)** → intet pysteps-kald og intet crash. Prognosen er tom (alle gennemsigtige), og widgetten viser "Ingen nedbør i området". Tests: `test_dry_history_returns_no_rain` (Task 3) og den manuelle UI-check (Task 7).
3. **Hul i historikken** (en 10-min-fil mangler) → nowcast bruger kun de seneste sammenhængende frames. Er der færre end 3, publiceres kun observationer med `forecast: null`. Test: `test_gap_in_history_gives_obs_only` (Task 6).
4. **Sommertid/vintertid** (skift 2026-10-25) → klokkeslæt i widgetten følger dansk tid på begge sider af skiftet. Test: `formatTime`-check i Task 7.
5. **Forældede data hos seeren** → `manifest.json` serveres `no-cache`. Widgetten genindlæser hvert 2. minut og viser "Data er N min gamle", når `generated` er over 30 min gammel. Test: manuel UI-check i Task 7 med et manipuleret manifest.

### Task 6: Cyklus (`python -m radar.run`)

**Files:**

**Interfaces:**
- Consumes: alle ovenstående.
- Produces: `run.cycle(now: datetime) -> str` returnerer `"published"`, `"unchanged"` eller `"failed"` (logges; `main()` returnerer altid exit 0, undtagen ved programmeringsfejl). State ligger i `out_dir()/state.json` (`{"last_t0": ISO}`).

Forløb: list fullRange siden `now − 130 min` → nyeste `t0`. Er `t0 == last_t0`, returneres `unchanged`. Ellers hentes de seneste `HISTORY_FRAMES`. Filer, der fejler, springes over. Findes filen for `t0 − 60 min`, scores den mod nuværende obs, linjen appendes til `out_dir()/verification.jsonl`, og filen slettes. Filer i `verify/` ældre end 3 t slettes. PNG og manifest skrives til `public_dir()`.
